Fundamentals

Algorithm

Алгоритм – это точное описание последовательности действий, которая приводит к решению задачи за конечное число шагов.

An algorithm is a precise description of a sequence of actions that leads to solving a problem in a finite number of steps.

Finiteness

The algorithm necessarily terminates after performing a `finite` number of steps.

Definiteness

Each step of the algorithm is precisely defined; the actions are strictly and unambiguously defined.

Input

The algorithm has an n-th (n ⩾ 0) number of input data

Output

The algorithm has an n-th (n > 0) number of output data.

Efficiency

All operators are simple enough to be executed accurately using pencil and paper.
